# Thermoform Studio

**➡️ [Generator öffnen / Open the generator](https://andys-3d-world.github.io/thermoform-studio/)**

Generator im Browser für 3D-druckbare Gitterplatten, die warm zwischen zwei Formen zu gewölbten Hälften eines hohlen Anhängers gepresst werden.

- Text, Icon, Gesicht oder eigenes SVG als Design
- 19 Umrissformen, 14 Lochmuster
- Rahmen mit Schraubverbindung und Clip-Scharnier
- Patrize und Matrize passend zur Form
- Export als 3MF (Bambu Studio, Farben schon zugewiesen) oder STL

Alles läuft lokal im Browser, es wird nichts hochgeladen.

Hinweis: Passungen (Gewinde, Clip) sind bisher nur rechnerisch geprüft, nicht gedruckt.
